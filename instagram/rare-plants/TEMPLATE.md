# レア植物 投稿文テンプレート

## 方針

- 語り口はブログと同じ「中津の花屋のスタッフが話しかける」調子。専門用語は一言で説明する。
- 何がレアなのか（流通量が少ない・生産者が少ない・この形/斑は珍しい 等）を最初の2行で伝える。Instagram は3行目以降が「続きを読む」で隠れるため。
- 植物の情報は、一般に確かなこと（原産地・性質・育て方の基本）だけを書く。価格・サイズ・株数など店の情報は、アップロード時に聞いたものだけを書き、推測で書かない。
- 「一点もの」「入荷数が少ない」は在庫リストのメモにある場合のみ。
- 本文は 400〜700 字程度。絵文字は見出しの頭に少しだけ。
- ハッシュタグは **合計5つ**。固定の4つ（#池田生花店 #中津市花屋 #中津市 #大分県花屋）＋その回の画像がわかるタグ1つ（基本は植物名。例：#アガベチタノタ）。

## 形式

```
【今週のレア植物】〈植物名〉

（1〜2行：一番の見どころ・なぜ珍しいか）

（本文：見た目の特徴、原産地や名前の由来、店に入ってきた経緯など）

🌱育て方のポイント
・置き場所：
・水やり：
・冬越し：

（締め：店頭で実物を見てほしい一言。在庫状況はメモにある場合のみ）

📍池田生花店（大分県中津市沖代町1-5-38）
☎ 0979-22-0171
🕘 9:00〜18:00（定休日：正月3日間）

#池田生花店 #中津市花屋 #中津市 #大分県花屋 #〈植物名〉
```

## 投稿ファイルに書くもの

1. 使う画像（`images/` のファイル名と、並べる順番）
2. 投稿文（そのままコピーして使える形）
3. 代替テキスト（画像の説明、1〜2文）
